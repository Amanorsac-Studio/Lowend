# Presets sent by testers

Presets received from beta testers are kept here, one folder per tester, as
they arrived (the `.rig.json` files from the app's Beta Presets folder):

```
beta/presets/
  <tester name or issue number>/
    <Preset name>.rig.json
```

Each file records who shared it (`sharedBy`), the version it came from
(`sharedFrom`) and the date (`sharedOn`). A submission arrives through a
**Preset submission** issue, whose form records the tester's permission, or by
email to hello@amanorsac.studio.

To try one: copy the file into `Documents/Amanorsac Studio/Low End/Presets/` and
choose **Rescan** in Settings › Library & backup. Its id is kept, so the same
preset sent twice replaces itself rather than appearing twice.

Before a preset ships as a factory preset, check that the submission's
permission box was ticked (or the email said so), and credit the tester as
they asked.
