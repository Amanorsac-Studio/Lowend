Low End test build

Version 1.0.0 · Amanorsac Studio

A test build of Low End, a bass amp, pedalboard and looper for the stage. It is not the released product.

It needs the test key you were sent, which Low End asks for when it first opens, and it stops working when that key expires.

The next pages show the licence, then every part you can install and exactly where each one goes. macOS will ask for your password once, because plug-ins are installed for every user of this Mac.
